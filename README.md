# 🎭 満席案内係

劇場の案内係になって、ポンコツなAI案内ロボと一緒にお客様を隙間なく座らせるブラウザゲームです。

▶ **遊ぶ:** https://taisuke-coder.github.io/manseki-annai/

- 通路側の席が埋まると奥には入れない(🔒)。奥から詰めて案内しよう
- 後ろ希望・前列希望・通路側希望のお客様、勝手に座る🙉マイペース客も来場
- AI案内ロボは時々ポンコツな判断をする。変だと思ったらクリックで阻止！
- 「2人で遊ぶ」で部屋を作ると、スマホからQRコード/部屋番号で参加して協力プレイできます

ファイルは `index.html` 1つだけです(2人プレイの通信に PeerJS を使用)。

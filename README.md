# 🎭 満席案内係

劇場の案内係になって、ポンコツなAI案内ロボと一緒にお客様を隙間なく座らせるブラウザゲームです。

▶ **遊ぶ:** https://taisuke-coder.github.io/manseki-annai/

- あなたは**調整役**。ご案内は入口ごとの誘導係ロボにおまかせ
- ロボがうまく座らせられなかったところを **移動・入れ替え・詰めて！** で直そう
- 入口は最初から複数。公演が進むと舞台横の扉からもお客様が入ってくる
- 通路側の席が埋まると奥には入れない(🔒)。ポンコツなロボや🙉マイペース客はクリックで止めよう
- 「2人で遊ぶ」で部屋を作ると、スマホからQRコード/招待リンク/部屋番号で参加して協力プレイできます

ファイルは `index.html` 1つだけです(2人プレイの通信に PeerJS を使用)。
